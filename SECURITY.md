# Security Policy

## Supported Versions

The following table details the security and update support status for the `XRumbled` repository (`Jamagoze/XRumbled`). Because this project involves low-level system integrations or performance utilities, only the latest commit on the `main` branch is actively supported with security patches and bug fixes.

| Version | Supported |
| :--- | :--- |
| Latest (`main`) | :white_check_mark: Yes |
| Previous Releases | :x: No |

---

## Reporting a Vulnerability

If you discover a security vulnerability, unexpected behavior, or stability risk within this repository, please report it responsibly rather than opening a public issue:

* **Reporting Channel:** Use GitHub's private vulnerability reporting feature or reach out directly through repository maintainer channels.
* **Information to Include:**
  * A detailed description of the vulnerability and its potential impact.
  * Environment details (e.g., operating system, device architecture, root/execution context, or target application package).
  * Any reproduction steps or proof-of-concept scripts that demonstrate the issue.

Maintainers will review the report and coordinate an appropriate patch before public disclosure.
